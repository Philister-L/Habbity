# Habbity

Простое одностраничное приложение для отслеживания привычек: добавляйте привычки, отмечайте выполнение и следите за недельной статистикой.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем перейдите на http://localhost:8000.
